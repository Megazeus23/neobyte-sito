Supprimer le compte

Sceaux de l’Éclipse, développé par NeoByte Studios.

Depuis le jeu

  1. Ouvrez le jeu et touchez votre nom en haut à gauche de l’écran principal.
  2. Ouvrez l’onglet Aide.
  3. Touchez Supprimer le compte.
  4. Écrivez le mot de confirmation demandé par le jeu et touchez le bouton pour supprimer le compte pour toujours.

Les étapes sont les mêmes sur Android et sur iPhone. La suppression est immédiate et définitive : la partie ne peut pas être récupérée. Toutes les sessions ouvertes sont fermées.

Les mêmes étapes valent aussi si vous jouez en tant qu’invité. En tant qu’invité, sans Google associé, se déconnecter supprime aussi la partie, comme Supprimer le compte : le jeu vous le rappelle avant la déconnexion.

Si vous associez Google depuis votre profil et que ce compte Google a déjà sa propre partie, le jeu vous demande laquelle garder : l’autre est supprimée pour toujours, comme avec Supprimer le compte.

Sans le jeu

Si vous n’avez plus le jeu installé, écrivez à privacy@neobytestudios.com depuis l’adresse e-mail de votre compte Google ou Apple, avec l’objet « Suppression du compte Sceaux de l’Éclipse ». Nous traitons la demande seulement si elle vient de la même adresse e-mail que celle avec laquelle vous vous connectez au jeu, et nous supprimons le compte dans les 30 jours, avec une réponse de confirmation. Si vous avez choisi de masquer votre e-mail avec Apple, supprimez le compte depuis le jeu comme expliqué ci-dessus.

Si vous jouez en tant qu’invité, nous n’avons pas votre e-mail : supprimez le compte depuis le jeu comme expliqué ci-dessus. Si vous avez déjà désinstallé le jeu, effacé ses données ou perdu votre téléphone sans avoir associé Google, la partie ne peut plus être récupérée : personne ne peut plus y entrer, et sans e-mail nous ne pouvons pas la reconnaître comme la vôtre. Une partie invité sans Google associé et sans connexion depuis 12 mois est supprimée automatiquement, comme avec Supprimer le compte.

Ce qui est supprimé et ce qui reste

  • Supprimés immédiatement : le lien avec votre compte Google ou Apple et son e-mail (en tant qu’invité, l’empreinte du code pour revenir), le nom de joueur, la progression, les cartes, les ressources, les missions et les sessions.
  • Profil public, Arène et Boss : sont supprimés immédiatement le profil que voient les autres joueurs (nom, portrait, cadre, titre, niveau et code), votre place et votre formation dans l’Arène avec vos combats et rediffusions, et vos dégâts aux Boss partagés : vous disparaissez de tous les classements. Les Boss que vous avez lancés restent ouverts pour les autres, sans votre nom.
  • Chat : sont supprimés immédiatement les messages que vous avez écrits dans le chat global, y compris les annonces de vos invocations, et vos chats privés, avec les messages que vous avez écrits et ceux que vous avez reçus.
  • Courrier : votre Courrier est supprimé immédiatement. Les messages que vous avez écrits à d’autres joueurs restent dans leur Courrier jusqu’à ce qu’ils les suppriment, mais sans votre nom : à la place de l’expéditeur, une mention indique que le joueur n’est plus dans le jeu.
  • Signalements et blocages : sont supprimés immédiatement les signalements faits sur vous, avec les copies de vos messages et de votre nom, les sanctions de modération sur votre compte, les blocages et les règles de la communauté que vous avez acceptées. Les suspensions des messages ou du compte encore en cours restent en revanche liées à l’empreinte des téléphones depuis lesquels vous avez joué, avec le type de blocage, le motif, l’échéance et la date mais sans lien avec votre compte, et s’appliquent à quiconque joue sur ces téléphones jusqu’à ce que le blocage expire ou soit levé (avec une suspension définitive, tant que le jeu est actif) : ainsi, on ne contourne pas le blocage avec un nouveau compte. Les signalements que vous avez faits sur d’autres, avec la copie du message ou du nom signalé, restent sans lien avec vous jusqu’à ce que nous les examinions ; après la décision, ils sont supprimés dans les 30 jours.
  • Sauvegardes : les données disparaissent aussi des copies de la base de données dans les 30 jours.
  • Achats : il ne reste qu’une empreinte irréversible du code d’achat, sans aucun lien avec vous, pour empêcher que le même achat soit utilisé deux fois. Les gemmes achetées et non dépensées sont perdues avec le compte. L’empreinte reste tant que le jeu est actif. Nous ne conservons pas de données fiscales des joueurs : les paiements sont encaissés par Google ou Apple, qui émettent les reçus.
  • Journaux techniques du serveur (adresse IP, heure, page demandée) : ils s’effacent tout seuls après 14 jours.

Désinstaller l’app ne supprime pas le compte : la partie reste sur le serveur. Avec Google ou Apple, vous la retrouvez en vous reconnectant ; en tant qu’invité, sans Google associé, vous ne pouvez plus revenir, et après 12 mois sans connexion la partie se supprime toute seule.
